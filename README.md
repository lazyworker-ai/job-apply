# job-apply skill

**让 AI 帮你投简历——用你自己的浏览器、你自己的登录，所以招聘网站看到的是一个正常人，而不是机器人。**

AI 操作的是你平时就在用的浏览器：**你自己的电脑、你自己的 IP、你自己的登录**。不用把账号密码交给任何人，也不在别人的服务器上登录。对招聘网站来说，就是你本人在正常浏览。

- **不能（只用网页版聊天）→ 别下载。** DeepSeek / 豆包 / 千问等纯网页聊天无法执行命令、连不到你电脑，这个 skill 帮不了你。

## 能做什么

- 在 **BOSS 直聘、猎聘、51job、智联招聘**上按你的条件（岗位、城市、最低薪资、方向、排除项）筛选岗位。
- 给你一份短名单。**你点头之后它才投递，绝不提前。** 你的点头只覆盖各平台默认的投递动作（默认打招呼语和/或在线简历）；任何自定义文案都要另外单独确认。
- 投递后对照平台自己的投递记录逐一核实，数字对得上才汇报。
- 按约定的时间扫描 HR 回复，**只起草回复给你确认**，绝不替你发送。

## 绝不做什么

- 绝不替你登录，绝不看你的密码，绝不替你注册账号。
- 绝不投递你没有批准的岗位。
- 未经你确认，绝不向 HR 或猎头发任何自定义文案。
- 绝不编造简历内容——只改写，不虚构。
- 绝不把你的浏览器暴露到网络。bridge 只绑定本机 localhost。

### 详细说明

本 skill 需要一个能读取 skill 文件、并能向浏览器桥（bridge）发 HTTP 请求的 AI 智能体。bridge 在你自己电脑的 `127.0.0.1:9224` 上监听，所以关键看 AI 跑在哪里。

| 平台 | 运行位置 | 模式 | 说明 |
| --- | --- | --- | --- |
| **WorkBuddy**（腾讯） | 你的电脑 | 本地 | **已实测 2026-11-09**（WorkBuddy v5.9.3）：selftest 10/10；并在 BOSS 上完整走完一轮「采集 → 详情页核实 → 用户确认 → 投递 → 消息中心回执核对」（1 个岗位）。其他三个平台的投递尚未测。桌面智能体，兼容 OpenClaw 技能，可选 DeepSeek、混元、Kimi、GLM 等模型；微信遥控时实际仍在你电脑上执行。请确认当前价格。 |
| **OpenClaw**（开源） | 你的电脑 | 本地 | 软件免费，可接任意模型（DeepSeek API、本地 Ollama 等），模型用量可能收费。 |
| **Manus Desktop** | 你的电脑 | 本地 | 本地执行命令，逐条授权。请确认价格。 |
| **Claude Code（装在你电脑上，含 Claude 桌面版 Code 标签的「本电脑」环境）** | 你的电脑 | 本地 | **已实测 2026-11-09**：本机跑 selftest 通过（9 通过 / 1 警告 / 0 失败，Chrome 157，9 个标签页）。需付费订阅；须在 Windows 本机运行，不能用 WSL 默认网络。Claude 桌面版聊天对话不算：它的命令在隔离虚拟机里执行，连不到本机 bridge；且它自带 Chrome 插件就能操作浏览器，本来就不需要搭桥，再者它是付费产品，本 skill 面向免费 AI 用户。 |
| **Codex（命令行/桌面版）** | 你的电脑 | 本地 | **已实测 2026-11-09**：本地跑 selftest 通过（9 通过 / 1 警告 / 0 失败），bridge 连通、四个站都能抓岗位。一般需 ChatGPT 订阅；默认沙箱可能禁网，需放开才能连到 bridge。 |
| **Meta Muse** | Meta 云端虚拟机 | **远程** | **已实测 2026-11-09**（自检通过）。有免费档。Muse 运行环境已在 tailnet 中，通过 SSH 本地转发连 bridge，不对外开 9224 端口（见 `references/bridge.md` → Option 1）。电脑需开 OpenSSH 服务。 |

| **网页聊天**（DeepSeek、豆包、千问、Kimi 网页版等） | 厂商服务器 | 不支持 | 无法执行命令或连到你电脑。只能把 `scripts/selftest.py` 的输出或岗位列表贴进去让它帮你判断，不能自动投递。 |

判断标准：**AI 能在你登录招聘网站的那台电脑上执行命令，就能用本地模式。** 云端智能体只能走远程模式，风险更高，优先选本地智能体。

价格和可用性经常变，用之前请先确认各厂商的免费档。只有标「已实测」的行做过完整测试，其余是按运行位置推断，未实测。未列出的平台是未测试，不是不支持。

## 安装（本地模式，6 步）

1. **装 bridge（一键）。** 右键 `scripts/setup-local.ps1` → 用 PowerShell 运行。它会装 Python（没有才装）、装 `websockets`、下载 Bridge v1.4.1、创建 `start-bridge.bat` 并启动服务。想一步步手动装，见 `references/bridge.md` 的 Install 一节。
2. **加载浏览器扩展。** 打开 `chrome://extensions`（Edge：`edge://extensions`），开启开发者模式，点「加载已解压的扩展程序」，选脚本最后提示的 `extension` 文件夹。
3. **确认 bridge 连上了。** 浏览器打开 `http://127.0.0.1:9224/health`，看到 `extension_connected: true` 即可。
4. **在你自己的浏览器里登录。** 打开四个招聘网站，自己登录。智能体绝不碰你的账号密码。
5. **设筛选条件。** 把 `criteria.example.yaml` 复制为 `criteria.yaml`，填好目标岗位、城市、薪资下限和排除项（也可以让 AI 问你后帮你填）。
6. **跑一次自检。** `python scripts/selftest.py`：只读，不投递；全部 PASS 再开始用。

以后每次使用前只需双击 `start-bridge.bat` 启动 bridge，用完关掉窗口。

然后让任意本地 AI 智能体（Claude Code、Codex、本地 DeepSeek 工具等）加载这个 skill，说一句："screen jobs for today"（筛选今天的岗位）。

不需要 Tailscale，不需要中继，不需要服务器。一切都在你自己的电脑上跑。

## 工作原理

```
你 ──► criteria.yaml（岗位、城市、薪资下限、排除项）
智能体 ──► 本机 127.0.0.1:9224 的 bridge API ──► 你的 Chrome/Edge（已登录）
智能体 ──► 收集 → 筛选（以详情页为准）→ 短名单 ──► 你点头 ──► 投递
智能体 ──► 对照平台记录核实 ──► 汇报真实数字
智能体 ──► 按约定时间扫描回复 ──► 只起草，你确认后才发
```

各平台的具体操作（含反爬虫注意事项和一周实测中遇到的所有坑）见 `references/platform-*.md`。规则——先点头、只起草、汇报前先核实——见 `references/governance.md`，具有约束力。

## 风险提示 / Risk warnings

- **自动化可能违反平台服务条款。** 招聘网站可能限制或封禁使用自动化的账号，风险自担。本 skill 不绕过登录、验证码或付费墙，也不会帮你投递你不符合条件的岗位。
- **猎聘有风控。** 短时间内连续打开很多岗位页面会触发安全验证（图形验证码）。出现验证时 skill 会停下，由你手动完成验证；请放慢操作节奏，不要循环重试。
- **BOSS 接口限流。** 高频直接调接口会返回 code 37（"环境存在异常"）。本 skill 改读页面自己的 Vue 岗位列表，不要去刷接口。
- **账号受限风险。** 如果平台标记了账号，投递和回复可能失效。请保持人类节奏（动作之间放慢），不要短时间内集中投递很多岗位；平台一旦限流就停下，不要硬闯。
- **bridge 没有认证（v1.4.1）。** 只能绑定 `127.0.0.1`，不要暴露到局域网或公网，用完就停。详见 `references/bridge.md` 的 Security 一节。

## 路线图

- **云端中继模式（以后，付费档）：** bridge 通过 websocket 主动向外拨号，这样智能体就能跑在云端。本 skill 不含此模式。
- **NexusBrowser：** bridge 的继任者，增加了令牌认证，是桥接层的候选升级。
- **简历定制：** 筛选后按目标 JD 定制简历——先快照原件，改完投递，归档用过的版本，再恢复原件。只改写，不虚构；每个版本用之前都要你点头。
